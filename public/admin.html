Telephony

Pick which provider places your outbound calls, and enter its credentials here instead of an environment variable — change providers or rotate a credential without redeploying.
Telnyx credentials save fine, but outbound calls still route through the Twilio-shaped call-control code underneath — placing a call with Telnyx selected will fail until that integration is actually built. Saving this now just means it's ready the moment that lands.

Live-call TTS provider

Only affects the per-sentence speech during a live conversation — the cached clips (opening line, backchannel, fallback, opt-out) always use Deepgram Aura regardless of this setting, since their cost is one-time either way.
Deepgram: model aura-asteria-en, no voice needed. OpenRouter: model hexgrad/kokoro-82m, voice e.g. af_bella. Self-hosted: model kokoro, base URL pointing at your deployed Kokoro-FastAPI service — use the internal/private network address if it's on the same host as this app, it's meaningfully faster than routing out over the public internet and back.
OpenRouter TTS hasn't been confirmed to support true low-latency streaming the way Aura does — the first sentence of a reply may take a bit longer to start playing. Test it in Voice Test before trusting it on real calls.
